## Modes

| Mode | Available |
| --- | :-: |
| Normal | ✅ |
| Fast | — |
| Search | ✅ |
| Generator | ✅ |
| Wait | ✅ |

La Grande Récré is one of the two stores with the full set of modes.

**Search** finds the product from a keyword instead of a URL, which is what you want when the product page does not exist yet at the time you set your tasks up.

**Wait** lets you chain tasks: run one task with a product and several with the input field empty, and the waiting ones fire as soon as the first carts. See [Tasks](/tasks).

**Generator** is available: create your La Grande Récré accounts from the [Generator](/generator) instead of signing up by hand.

## Checkout

La Grande Récré works by **payment link**, with a card or with PayPal. Stacked carts the item and hands you a link to finish the payment yourself.

<Warning>
  A payment link is not an automatic checkout. Stay reachable during the drop, because the order is only secured once you have completed the payment.
</Warning>

## Setting up a task

The task form is the same on every store — see [Tasks](/tasks) for what each field does. For La Grande Récré:

<Steps>
  <Step title="Pick the site">
    Select **La Grande Récré** in the Site dropdown.
  </Step>
  <Step title="Enter the product">
    Paste the product URL or its SKU, type a keyword if you are running **Search**, or leave the field empty to put the task in **Wait** mode.
  </Step>
  <Step title="Choose the mode">
    **Normal**, **Search** or **Wait** depending on how the drop works.
  </Step>
  <Step title="Attach your groups">
    Profile group, account group and proxy group.
  </Step>
</Steps>

<Note>
  Store-specific notes will be added here as they come up: proxy types that work best, delays that hold on a drop, and anything La Grande Récré does differently.
</Note>
