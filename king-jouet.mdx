## Modes

| Mode | Available |
| --- | :-: |
| Normal | ✅ |
| Fast | ✅ |
| Search | — |
| Generator | — |
| Wait | — |

**Fast** is the mode to run on King Jouet. Keep a few **Normal** tasks on the same drop as a fallback.

There is no Generator on King Jouet, so your accounts have to be created by hand and added in [Accounts](/accounts).

## Checkout

King Jouet supports **credit card auto checkout**: Stacked completes the payment itself, with no action from you.

## Setting up a task

The task form is the same on every store — see [Tasks](/tasks) for what each field does. For King Jouet:

<Steps>
  <Step title="Pick the site">
    Select **King Jouet** in the Site dropdown.
  </Step>
  <Step title="Enter the product">
    Paste the product URL or its SKU.
  </Step>
  <Step title="Choose the mode">
    **Fast** for the drop itself, **Normal** on a few tasks as backup.
  </Step>
  <Step title="Attach your groups">
    Profile group, account group and proxy group. Make sure the profile carries a card, since King Jouet checks out automatically.
  </Step>
</Steps>
