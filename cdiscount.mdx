## Modes

| Mode | Available |
| --- | :-: |
| Normal | ✅ |
| Fast | ✅ |
| Search | — |
| Generator | ✅ |
| Wait | — |

**Fast** is the mode to run on Cdiscount. Keep a few **Normal** tasks on the same drop as a fallback.

**Generator** is available: create your Cdiscount accounts from the [Generator](/generator) instead of signing up by hand.

## Setting up a task

The task form is the same on every store — see [Tasks](/tasks) for what each field does. For Cdiscount:

<Steps>
  <Step title="Pick the site">
    Select **Cdiscount** in the Site dropdown.
  </Step>
  <Step title="Enter the product">
    Paste the product URL or its SKU.
  </Step>
  <Step title="Choose the mode">
    **Fast** for the drop itself, **Normal** on a few tasks as backup.
  </Step>
  <Step title="Attach your groups">
    Profile group, account group and proxy group.
  </Step>
</Steps>

<Note>
  Store-specific notes will be added here as they come up: proxy types that work best, delays that hold on a drop, and anything Cdiscount does differently.
</Note>
