Queue-IT is not a store. It is the waiting room software that many retailers put in front of a drop, and Stacked treats it as a module of its own.

**Every Queue-it waiting room is supported**, whichever retailer is using it.

## What it does

The module lets you run a large number of tasks that enter the queue and wait in it **like a human would**. More tasks in the queue means more chances that one of them reaches the front early.

When a task gets through, it sends you a **link that opens the site on the other side of the queue**.

## The Chrome extension

This is where the [Chrome extension](/installation) earns its place. When you open the link, the extension **transfers the session cookies automatically**, so your browser lands on the session that came out of the queue instead of being sent back to the end of the line.

<Warning>
  Without the extension installed, opening the link puts you straight back into the waiting room. Install it before a Queue-it drop, not during.
</Warning>

## Setting up a task

The task form is the same on every store — see [Tasks](/tasks) for what each field does. For Queue-IT:

<Steps>
  <Step title="Pick the site">
    Select **Queue-IT** in the Site dropdown.
  </Step>
  <Step title="Point it at the queue">
    Enter the URL of the page protected by the waiting room.
  </Step>
  <Step title="Create a lot of tasks">
    Use the **Tasks to create** counter. Queue-IT is a numbers game: the more positions you hold, the better your best position.
  </Step>
  <Step title="Attach a proxy group">
    Each task needs its own way out, so a solid proxy group matters more here than anywhere else.
  </Step>
</Steps>

<Note>
  Store-specific notes will be added here as they come up: which retailers use Queue-it, and how early to start queueing for a given drop.
</Note>
