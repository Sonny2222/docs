## Modes

| Mode | Available |
| --- | :-: |
| Normal | ✅ |
| Fast | ✅ |
| Search | — |
| Generator | ✅ |
| Wait | — |

**Fast** is the mode to run on Fnac. Keep a few **Normal** tasks running on the same drop as a fallback.

**Generator** is available, so you can create your Fnac accounts from the [Generator](/generator) instead of signing up by hand.

## Checkout

Fnac supports **credit card auto checkout**: Stacked completes the payment itself, with no action from you.

## Setting up a task

The task form is the same on every store — see [Tasks](/tasks) for what each field does. For Fnac:

<Steps>
  <Step title="Pick the site">
    Select **Fnac** in the Site dropdown.
  </Step>
  <Step title="Enter the product">
    Paste the product URL or its SKU. Leave the field empty to run the task in Wait mode behind another one.
  </Step>
  <Step title="Choose the mode">
    **Fast** for the drop itself, **Normal** on a few tasks as backup.
  </Step>
  <Step title="Attach your groups">
    Profile group, account group and proxy group. Fnac requires an account, so make sure the account group is filled.
  </Step>
</Steps>

<Note>
  Store-specific notes will be added here as they come up: proxy types that work best, delays that hold on a drop, and anything Fnac does differently.
</Note>
