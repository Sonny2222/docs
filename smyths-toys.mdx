## Modes

| Mode | Available |
| --- | :-: |
| Normal | ✅ |
| Fast | ✅ |
| Search | — |
| Generator | — |
| Wait | — |
| Preorder | ✅ |

**Fast** is the mode to run on Smyths Toys. Keep a few **Normal** tasks on the same drop as a fallback.

**Preorder** is specific to Smyths Toys, for the releases the store opens to pre-order rather than selling on the day.

There is no Generator here, so your accounts have to be created by hand and added in [Accounts](/accounts).

## Checkout

Smyths Toys is the one store that gives you both routes, and the one you pick changes what happens at the end of the drop:

| Payment method | What happens |
| --- | --- |
| **Credit card** | Auto checkout. Stacked completes the payment itself. |
| **PayPal** | Payment link. Stacked carts the item and hands you a link to pay yourself. |

<Tip>
  Run credit card if you want the order secured without touching anything. Keep PayPal for when you would rather review the order before paying.
</Tip>

## Setting up a task

The task form is the same on every store — see [Tasks](/tasks) for what each field does. For Smyths Toys:

<Steps>
  <Step title="Pick the site">
    Select **Smyths Toys** in the Site dropdown.
  </Step>
  <Step title="Enter the product">
    Paste the product URL or its SKU.
  </Step>
  <Step title="Choose the mode">
    **Fast** for a live drop, **Preorder** when the release is open to pre-order.
  </Step>
  <Step title="Pick your payment method">
    Credit card for auto checkout, PayPal for a payment link.
  </Step>
</Steps>

<Note>
  Store-specific notes will be added here as they come up: proxy types that work best, delays that hold on a drop, and anything Smyths Toys does differently.
</Note>
