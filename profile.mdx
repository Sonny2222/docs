A profile holds everything Stacked needs to complete a checkout: the account it signs in with, where the order ships, and how it pays. You can create as many as you need.

## Profile groups

Profiles live inside groups, and you can create as many groups as you want — for example **Main**, **ACO/PAS**, or whatever matches the way you run your drops. Each group can hold multiple profiles.

<Tip>
  Group profiles the way you actually use them. On drop day you pick a group, so a clean split saves you time when it matters.
</Tip>

## Creating a profile

Click **Create Profile**. The form is split into four tabs and most fields speak for themselves. The points worth knowing:

### Basic

**Profile name** is the only required field. It is what you will see when picking a profile later, so make it recognisable.

The **email** and **password** are the credentials of the retailer account this profile uses.

**IMAP** lets Stacked read the mailbox tied to that account, which is what makes verification and confirmation emails usable. Note that the field asks for an **app password**, not your normal mailbox password: providers such as Gmail require you to generate a dedicated one in your account security settings.

The **Discord webhook** here is per profile, so you can send a given profile's notifications to their own channel.

### Shipping

The delivery address and phone number for this profile.

The **Use shipping as billing address** toggle is on by default. Leave it on when both addresses match; switch it off and the **Billing** tab is where you enter a different one.

### Payment

Pick a **payment type** — PayPal, Manual or Browser — then fill in the card details underneath.

## Bulk import

Filling the form profile by profile gets old fast. **Bulk import** takes a CSV instead: build or edit your profiles in a spreadsheet, drag the file into the bot, and they are all created at once.

It is also the easiest way to change many profiles at the same time — edit the column in your spreadsheet, import again, done.

<Card title="Download the CSV template" icon="file-csv" href="https://raw.githubusercontent.com/Sonny2222/docs/main/files/profiles_format.csv">
  `profiles_format.csv`: the header row Stacked expects, plus one example profile. If it opens in your browser instead of downloading, right-click the card and choose **Save Link As**.
</Card>

<Steps>
  <Step title="Prepare your CSV">
    Open the template in Excel, Numbers or Google Sheets and fill in one profile per row. Keep the header row exactly as it is, and save the file as CSV.
  </Step>
  <Step title="Open Profiles and pick a group">
    Go to **Profiles**. The **Groups** column lists your profile groups; click **+** to create a new one if needed.
  </Step>
  <Step title="Drop the file on the group">
    Drag the CSV from Finder or File Explorer onto the group name. The row highlights and shows **Drop CSV to import**. Release, and the profiles are created in that group.
  </Step>
</Steps>

<Frame caption="Drag the CSV onto a group in Profiles, then release when it shows Drop CSV to import.">
  <img src="/images/profiles-bulk-import.png" alt="Dragging a CSV file onto a profile group in Stacked, with the Drop CSV to import hint" />
</Frame>

<Accordion title="Template columns">

```csv profiles_format.csv
name,email,password,imapEmail,imapPassword,webhook,shipping.firstName,shipping.lastName,shipping.line1,shipping.line2,shipping.houseNumber,shipping.state,shipping.city,shipping.postcode,shipping.country,shipping.phone,billing.firstName,billing.lastName,billing.line1,billing.line2,billing.houseNumber,billing.state,billing.city,billing.postcode,billing.country,billing.phone,payment.cardHolder,payment.cardNumber,payment.expiryMonth,payment.expiryYear,payment.cvc
imported,random@gmail.com,,,,,random,random,,,,,,,France,random,,,,,,,,,,,,,,,
```

  - `name`: the profile name shown in Stacked.
  - `email`, `password`: the retailer account this profile uses. `imapEmail`, `imapPassword`: the mailbox Stacked reads, with an app password.
  - `shipping.*` and `billing.*`: the two addresses.
  - `payment.*`: the card details.

</Accordion>

<Tip>
  A spreadsheet is where the placeholders below really pay off: you can apply `random` and `XXX` across dozens of rows in one go.
</Tip>

## Randomising a profile

Two fields accept placeholders that Stacked replaces with random values at checkout, so several profiles built on the same real address do not look identical to the store.

<CardGroup cols={2}>
  <Card title="Random name" icon="user">
    Type `random` in **First name** and **Last name** instead of a real name. Stacked generates a different name on each checkout.
  </Card>
  <Card title="Address jig" icon="location-dot">
    Insert `XXX` anywhere in the address. Stacked replaces each one with a random three-letter string.
  </Card>
</CardGroup>

**Example.** For the real address *1 rue Victor Hugo, 69002 Lyon*:

| | |
| --- | --- |
| What you enter | `1 XXX rue Victor Hugo XXX` |
| What the store receives | `1 RTZ rue Victor Hugo CPQ` |

The parcel still reaches you: the street name, the house number and the post code are left untouched.

<Warning>
  A profile contains real payment details. Treat your profiles like you would treat the card itself, and never share or post them — an exported CSV included.
</Warning>
