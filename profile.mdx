A profile holds everything Stacked needs to complete a checkout: the account it signs in with, where the order ships, and how it pays. You can create as many as you need.

## Profile groups

Profiles live inside groups, and you can create as many groups as you want — for example **Main**, **ACO/PAS**, or whatever matches the way you run your drops. Each group can hold multiple profiles.

<Tip>
  Group profiles the way you actually use them. On drop day you pick a group, so a clean split saves you time when it matters.
</Tip>

## Creating a profile

Click **Create Profile**. The form is split into four tabs and most fields speak for themselves. The points worth knowing:

### Basic

**Profile name** is the only required field. It is what you will see when picking a profile later, so make it recognisable.

The **email** and **password** are the credentials of the retailer account this profile uses.

**IMAP** lets Stacked read the mailbox tied to that account, which is what makes verification and confirmation emails usable. Note that the field asks for an **app password**, not your normal mailbox password: providers such as Gmail require you to generate a dedicated one in your account security settings.

The **Discord webhook** here is per profile, so you can send a given profile's notifications to their own channel.

### Shipping

The delivery address and phone number for this profile.

The **Use shipping as billing address** toggle is on by default. Leave it on when both addresses match; switch it off and the **Billing** tab is where you enter a different one.

### Payment

Pick a **payment type** — PayPal, Manual or Browser — then fill in the card details underneath.

## Randomising a profile

Two fields accept placeholders that Stacked replaces with random values at checkout, so several profiles built on the same real address do not look identical to the store.

<CardGroup cols={2}>
  <Card title="Random name" icon="user">
    Type `random` in **First name** and **Last name** instead of a real name. Stacked generates a different name on each checkout.
  </Card>
  <Card title="Address jig" icon="location-dot">
    Insert `XXX` anywhere in the address. Stacked replaces each one with a random three-letter string.
  </Card>
</CardGroup>

**Example.** For the real address *1 rue Victor Hugo, 69002 Lyon*:

| | |
| --- | --- |
| What you enter | `1 XXX rue Victor Hugo XXX` |
| What the store receives | `1 RTZ rue Victor Hugo CPQ` |

The parcel still reaches you: the street name, the house number and the post code are left untouched.

<Warning>
  A profile contains real payment details. Treat your profiles like you would treat the card itself, and never share or post them.
</Warning>
